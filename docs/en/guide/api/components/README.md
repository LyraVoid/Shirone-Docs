This directory will host documentation for external props, export methods, and event hooks across Shirone's UI modules:

- **Sidebar Widget APIs** (Music player, announcements, profile cards, etc.)
- **Page Component APIs** (Anime grid, moments stream, projects cards, etc.)
- **Markdown Extension Component APIs** (Bilibili facade, gallery grid, etc.)
