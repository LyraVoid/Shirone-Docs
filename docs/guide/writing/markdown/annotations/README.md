内容注释提供了比传统脚注更为生动、交互式的旁注说明系统，支持行内标记与右侧边缘卡片联动。

## 语法格式

在正文中使用 `[+tag]` 插入引用标记，并在下方或文末定义注释块：

```markdown
Astro 采用孤岛架构 [+islands] 来保持页面的极速加载。

[+islands]:
  孤岛架构指由静态 HTML 所包裹的独立交互组件区域，只有交互区域才加载 JavaScript。
```

## 渲染效果与交互

- **行内标记**：正文中的标记呈现为精巧的高亮徽标。
- **桌面端旁注**：在大屏幕设备上，注释内容优雅地显示在右侧边栏旁注区域。
- **移动端弹出**：在触屏或窄屏设备上，轻触标记即可唤出居中浮层卡片查看详细注释。
- **纯静态输出**：注释内容直接由服务端输出，兼顾无障碍访问与爬虫抓取。
