提示容器用于在文章中高亮特定级别的提示、警告、注意或可折叠区域，严格遵循 Material 3 Expressive 的容器表面分层设计。

## 语法格式

支持方括号标题与空格标题两种书写形式：

```markdown
::: tip[操作提示]
建议在修改核心配置前先运行类型检查。
:::

::: warning 部署前检查
若未配置正式域名，社交分享卡片可能无法正确生成。
:::

::: info 相关参考
关于双仓架构的更多细节，请参阅内容分离指南。
:::

::: caution 破坏性操作
执行此命令将清除本地未提交的改动。
:::

::: details 点击展开详细日志
构建过程的详细输出如下：
- 同步完成
- 生成静态 HTML 成功
:::
```

## 支持的容器类型

| 类型 | 语义 | 视觉风格 |
| --- | --- | --- |
| `tip` | 技巧与建议 | 强调色彩容器与灯泡图标 |
| `info` | 补充信息 | 主色调表面与信息图标 |
| `warning` | 注意与预警 | 警示色调与三角感叹号 |
| `caution` | 危险操作 | 错误色调与高对比警示框 |
| `important` | 关键重点 | 鲜亮强调容器 |
| `note` | 普通笔记 | 中性表面容器 |
| `details` | 折叠面板 | 带箭头的原生 details 折叠组件 |
