Shirone 增强了 GitHub Flavored Markdown 标准表格的排版与交互体验，在构建期通过专门的渲染插件自动生成响应式滚动包裹层。

## 标准表格语法

```markdown
| 功能模块 | 对应状态 | 默认值 | 说明 |
| :--- | :---: | :---: | --- |
| 动态配色 | 稳定 | 315 | 默认粉紫色色相 |
| 无刷新切页 | 启用 | true | 基于 Swup 4 框架 |
| 零额外负担 | 严格遵循 | true | 页面关闭功能时零请求零体积 |
```

## 对齐方式

- `:---`：左对齐
- `:---:`：居中对齐
- `---:`：右对齐

## 移动端响应式支持

在窄屏或移动端设备上，当表格列数较多或内容超出屏幕宽度时：
- 构建期插件自动为表格注入外层响应式容器与平滑滚动样式。
- 绝不会发生撑破页面视口或导致水平全局溢出的情况。
- 表头固定与交替斑马纹背景完全遵循 Material 3 Expressive 的表面容器设计规范。
