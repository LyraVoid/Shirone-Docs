缩写词语法用于在文章中对专业术语进行统一定义，并在正文中自动渲染为带有原生气泡提示的 `<abbr>` 元素。

## 语法格式

在文章任意位置（通常在文末或章节开头）声明缩写词字典：

```markdown
*[SSR]: 服务端渲染技术
*[LCP]: 最大内容绘制时间指标
*[AST]: 抽象语法树
```

随后在正文直接书写该缩写词：

```markdown
采用 SSR 可以大幅优化站点的 LCP 表现，并在 AST 解析阶段完成静态转换。
```

## 渲染机制

- **自动匹配**：同一文章中所有匹配到的词条都会自动转换为带有语义下划线的缩写词。
- **现代化气泡定位**：采用原生 Popover 顶层与 CSS Anchor 定位技术，悬浮窗不会被侧栏或父容器边界遮挡裁剪，无需等待浏览器默认的 title 延迟。
- **按需加载**：只有在检测到缩写词语法的文章中才会激活轻量交互模块。
