隐秘文本（黑幕防剧透）用于遮盖关键剧情、谜题答案或敏感信息，读者在鼠标悬停或触屏轻触后方可显现内容。

## 语法格式

使用 `:spoiler` 指令包裹隐藏内容：

```markdown
这个故事最后的结局是 :spoiler[真相其实是两个人早已相识]。

最终通关的正确密码为 :spoiler[42-7890]。
```

## 交互与特性

- 默认状态下呈现不透明的防剧透遮罩背景。
- 鼠标悬停（桌面端）或点击（移动触屏端）时柔和淡入真实文字。
- 使用纯 CSS 与轻量交互实现，兼顾移动设备兼容性与阅读隐私。
