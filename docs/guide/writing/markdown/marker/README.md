马克笔语法为正文中的短语提供醒目的荧光高亮视觉效果，基于原生语义化 `<mark>` 标签渲染。

## 基础语法

使用成对的双等号 `==` 包裹需要高亮的文字：

```markdown
在撰写文章时，使用 ==主题主色高亮== 标记核心要点与结论。
```

## 语义状态后缀

可以通过大括号后缀指定特定的语义色彩角色：

```markdown
==次级强调状态=={.secondary}

==警告与需要修正的条件=={.error}

==建议与辅助提示=={.tip}

==三级调色板强调=={.tertiary}
```

## 渲染特性

- 生成标准的 `<mark>` HTML 标签，保障屏幕阅读器与辅助工具的可访问性。
- 高亮背景色完全由 Material 3 Expressive 的语义调色板驱动，与站点的主题色动态同步。
- 纯服务端渲染，无任何客户端脚本开销。
