此处为 Shirone 组件级 API 与二次开发接口文档框架。

## 规划结构

本目录用于承载 Shirone 各个核心 UI 组件、侧边栏小部件与 Markdown 扩展组件的对外导出接口、事件钩子及 Props 规范：

- **侧栏组件 API**（音乐播放器、公告栏、博主信息等）
- **页面组件 API**（番剧网格、瞬间瀑布流、项目卡片等）
- **Markdown 扩展组件 API**（哔哩哔哩门面、画廊网格等）
